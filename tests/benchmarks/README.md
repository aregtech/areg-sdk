# Areg Framework benchmarks

This directory contains the performance benchmarks of the Areg Framework. They are
written with [Google Benchmark](https://github.com/google/benchmark) and are compiled
against the [CodSpeed compatibility layer](https://github.com/CodSpeedHQ/codspeed-cpp),
which behaves exactly like the upstream library when CodSpeed is not enabled.

## What is measured

| File                        | Scope                                                                                  |
| --------------------------- | -------------------------------------------------------------------------------------- |
| `StringBenchmark.cpp`       | `areg::String` construction, append, format, search, replace, split, conversions, CRC32 |
| `ContainerBenchmark.cpp`    | `ArrayList`, `LinkedList`, `SortedLinkedList`, `HashMap`, `OrderedMap`, `Stack`, `RingStack` |
| `SharedBufferBenchmark.cpp` | `areg::SharedBuffer` serialization and de-serialization, the base of the IPC messaging  |
| `DateTimeBenchmark.cpp`     | `areg::DateTime` timestamping, decomposition and formatting, used by the logging        |

All input data is generated by `BenchmarkUtils.hpp` from a fixed seed, so that every run
of a benchmark operates on exactly the same data.

## Building and running

The benchmarks are not part of the default build. Enable them with the `AREG_BENCHMARKS`
option:

```bash
cmake -B ./build -DCMAKE_BUILD_TYPE=Release -DAREG_BENCHMARKS=ON -DAREG_TESTS=OFF -DAREG_EXAMPLES=OFF
cmake --build ./build --target areg-benchmarks -j
```

The executable is placed in the Areg binary output directory, for example
`./product/build/gnu-c++/linux-64-x86_64-release-shared/bin/areg-benchmarks.elf`.
Run it to execute the complete suite:

```bash
./product/build/gnu-c++/linux-64-x86_64-release-shared/bin/areg-benchmarks.elf
```

Google Benchmark filters are supported, for example
`--benchmark_filter=BM_String_.*` to run only the string benchmarks.

## Running with CodSpeed

To measure the benchmarks with the CodSpeed CPU simulation instrument, add the
`CODSPEED_MODE` flag when configuring the project, and add `-g` so that the report
contains the source information:

```bash
cmake -B ./build -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_FLAGS=-g \
      -DAREG_BENCHMARKS=ON -DAREG_TESTS=OFF -DAREG_EXAMPLES=OFF \
      -DAREG_BIN_DIR=$PWD/build/bin -DCODSPEED_MODE=simulation
cmake --build ./build --target areg-benchmarks -j
codspeed run --mode simulation -- ./build/bin/areg-benchmarks.elf
```

The same steps run on every push and pull request through the
`.github/workflows/codspeed.yml` workflow.
